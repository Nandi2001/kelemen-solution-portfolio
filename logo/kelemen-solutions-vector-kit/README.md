# Kelemen Solutions — Vector Brand Kit

This kit is a manually reconstructed, vector interpretation of the selected generated "KS" logo concept. It is not a pixel-perfect auto-trace of the image.

## Files
- `ks-icon-transparent.svg`: transparent compact monogram for flexible use
- `ks-icon-dark.svg`: dark rounded-square app/social icon
- `ks-icon-blueprint.svg`: dark icon with subtle engineering graph grid
- `ks-icon-light.svg`: light-background icon
- `ks-horizontal-transparent.svg`: slim, one-line website-header lockup
- `ks-horizontal-dark.svg`: same lockup on a dark canvas
- `ks-primary-transparent.svg`: primary stacked two-row lockup
- `ks-primary-dark.svg`: primary stacked lockup on dark canvas
- `ks-primary-blueprint.svg`: vector engineering blueprint-style banner
- `ks-icon-single-color-white.svg`: one-color white mark
- `ks-icon-single-color-black.svg`: one-color dark mark

## Brand colors
- Teal: `#14B8A6`
- White: `#F8FAFC` (light variants use `#FFFFFF` backgrounds)
- Charcoal: `#0B1116`

## Editability
All elements are real SVG paths/lines/shapes, including the outlined letterforms. No live fonts, bitmap elements, or external URLs are required. Open in Inkscape, Illustrator, Figma, or a code editor.

## Usage on GitHub / Cloudflare Pages
Upload the SVGs into e.g. `/assets/` and use:

```html
<link rel="icon" type="image/svg+xml" href="/assets/ks-icon-dark.svg">
<img src="/assets/ks-horizontal-transparent.svg" alt="Kelemen Solutions" width="300">
```

For a static website, GitHub Pages and Cloudflare Pages can serve SVGs directly.

Note: Before registering a trademark or using the mark commercially, independently check for similar marks and finalize your visual identity.
